# YouLoad

Программа для скачивания видео и звука с YouTube со встроенным обходом замедления в России. Windows, macOS и Linux.

**[Скачать последнюю версию](https://github.com/Liidioteee/YouLoad/releases/latest)**

## Возможности

**Видео и звук**
- Качество до 8K, HDR, 60 кадров; кодеки AV1, VP9 и H.264; контейнеры MP4, MKV и WebM
- Выбор звуковой дорожки: оригинал или дубляж
- Только звук: MP3, M4A, Opus, FLAC, WAV с выбором битрейта
- Субтитры (вшитые или .srt), обложка, теги, главы
- Скачивание фрагмента по времени
- Таблица всех форматов для ручного выбора

**Плейлисты и каналы**
- Выбор роликов галочками, поиск, «Только новые»: YouLoad помнит, что уже скачано
- Вкладки канала: видео, Shorts, трансляции
- Оценка размера до начала загрузки

**Удобство**
- Пресеты: «Обычное», «Максимум», «Для телефона», «Только звук» и свои
- Очередь с паузой; незаконченные загрузки продолжаются после перезапуска
- История скачанного с поиском, списком и сеткой
- Вставка ссылки через Ctrl+V в любом месте окна, перетаскивание, слежение за буфером обмена
- Уведомления, значок в трее, ограничение скорости, прокси, файл cookies для роликов 18+
- Русский и английский язык, светлая и тёмная тема
- Автообновление с проверкой подписи

## Обход блокировок

YouTube в России замедляют на оборудовании провайдеров. YouLoad запускает [zapret](https://github.com/bol-van/zapret), и замедление перестаёт распознавать соединение. VPN не нужен.

- **Работает только пока YouLoad открыт.** В это время YouTube в браузере тоже ускоряется. Закрыли программу — обход выключился.
- **Windows:** winws из zapret со стратегиями из сборки [Flowseal](https://github.com/Flowseal/zapret-discord-youtube), по умолчанию ALT. Действует только на домены YouTube. Запускается службой YouLoad Bypass, поэтому прав администратора при каждом запуске не просит.
- **Автоподбор:** YouLoad перебирает стратегии и оставляет первую, с которой видео качается быстро.
- **Если zapret у вас уже запущен,** YouLoad пользуется им и свой не запускает.
- **macOS и Linux:** экспериментально, через tpws как локальный прокси только для загрузок YouLoad.

## Установка

| Система | Файл |
|---|---|
| Windows 10/11 x64 | `YouLoad_<версия>_x64-setup.exe` |
| macOS, Apple Silicon | `YouLoad_<версия>_aarch64.dmg` |
| macOS, Intel | `YouLoad_<версия>_x64.dmg` |
| Linux | `YouLoad_<версия>_amd64.AppImage` или `.deb` |

- **Windows.** Установщик один раз попросит права администратора: он ставит службу YouLoad Bypass. Установщик пока не подписан, поэтому SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае». Если антивирус блокирует zapret (драйвер WinDivert), добавьте папку YouLoad в исключения.
- **macOS.** Приложение не подписано: при первом запуске откройте его через правый клик → «Открыть».
- **Linux.** AppImage сделайте исполняемым и запустите.

Контрольные суммы SHA-256 есть в описании каждого релиза и в файле `SHA256SUMS.txt`.

## Сборка из исходников

Нужны Node.js 22+ и Rust (stable). На Windows — Visual Studio Build Tools с компонентом C++, на Linux — пакеты WebKitGTK для Tauri.

```bash
npm install
npm run fetch-tools
npm run dev
```

`fetch-tools` скачивает yt-dlp, FFmpeg, Deno и zapret закреплённых версий для вашей системы и проверяет их SHA-256 (`scripts/tools.json`). Для другой платформы: `node scripts/fetch-tools.mjs --platform macos-arm64`.

Установщик для своей системы: `npm run build`.

## Как устроено

| Часть | Где |
|---|---|
| Интерфейс (React, TypeScript) | `apps/desktop/src` |
| Ядро (Rust, Tauri 2) | `apps/desktop/src-tauri/src` |
| Загрузка | yt-dlp, FFmpeg, Deno |
| Обход | `apps/desktop/src-tauri/src/bypass` |
| Сторонние компоненты | `scripts/fetch-tools.mjs`, `scripts/tools.json` |

**Безопасность обхода.** Служба и запасной помощник запускают только winws со стратегиями, зашитыми в программу при сборке, и сначала сверяют хеши файлов zapret. Канал к службе доступен только пользователям, вошедшим в систему. Когда программа закрывается или падает, служба сразу останавливает winws.

**Без телеметрии.** YouLoad обращается только к YouTube и к GitHub (обновления yt-dlp и самой программы).

## Релизы

Тег вида `v1.2.3` запускает сборку для всех платформ в GitHub Actions (`.github/workflows/release.yml`). Получается черновик релиза с установщиками и подписанным файлом автообновления. Для подписи нужны секреты `TAURI_SIGNING_PRIVATE_KEY` и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`.
